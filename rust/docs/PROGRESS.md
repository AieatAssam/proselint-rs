# Migration progress

## Current state

- Updated process cadence: keep focused Rust/live parity and an independent focused verifier for every capability; batch the cumulative live gate every 5–10 recorded capabilities, before release, and immediately after shared matcher/config/CLI/output changes. This should cut cumulative-gate invocations by about 80–90% versus running one after every capability in a stable batch, while preserving the per-capability checks. Stage durations and case counts are now required in each capability record. Benchmarking stays separate, with exact-workload live preflight and a whole-run deadline. POSIX process groups are terminated on timeout; detached descendants and the current Windows direct-child-only cleanup remain limits.
